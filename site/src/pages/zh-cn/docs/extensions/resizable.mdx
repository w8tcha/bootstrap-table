列宽调整扩展允许用户通过拖拽表头边界的方式调整表格列的宽度。无任何外部依赖（不再需要 jQuery 和 jquery-resizable-columns），支持鼠标、触控笔和触摸操作。

## 用法

```html
<script src="extensions/resizable/bootstrap-table-resizable.js"></script>
```

## 示例

[Resizable](https://examples.bootstrap-table.com/#extensions/resizable.html)

## 选项

### resizable

- **属性:** `data-resizable`

- **类型:** `Boolean`

- **详情:**

  是否启用列宽调整功能。设置为 `true` 时，用户可以通过拖拽列边界来调整列宽。

- **默认值:** `false`

### resizableMinWidth

- **属性:** `data-resizable-min-width`

- **类型:** `Number`

- **详情:**

  调整列宽时，列可被缩小到的最小宽度（像素）。

- **默认值:** `30`

## 持久化列宽

列宽在重新渲染（例如显示/隐藏列）后会保留。如需在页面刷新后保留列宽，请加载 [store.js](https://github.com/marcuswestin/store.js)（使 `window.store` 可用），并为表格设置 `data-resizable-columns-id` 属性。列宽按列的 `data-field` 保存。

## 样式

拖拽手柄渲染为 `.rc-handle-container` 中的 `.rc-handle` 元素；拖拽过程中表格会添加 `rc-table-resizing` 类。
